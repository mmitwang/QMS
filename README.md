# QMS质量管理系统

## 系统简介

QMS质量管理系统是专为浙江腾腾电气设计的质量管理解决方案，提供全面的质量控制、检验、分析和管理功能。系统采用现代化的Web技术栈，为企业提供高效、专业的质量管理工具。

## 功能特性

### 🔍 质量检验管理
- **来料检验**: 原材料和外购件质量检验
- **过程检验**: 生产过程中的质量控制点检验
- **成品检验**: 最终产品质量检验
- **出厂检验**: 产品出厂前的最终质量确认

### 📊 质量控制
- **SPC统计控制**: 统计过程控制图表和分析
- **过程控制**: 生产过程质量控制点管理
- **预防控制**: 质量问题预防措施管理

### 📈 质量分析
- **趋势分析**: 质量数据趋势分析和预测
- **帕累托分析**: 质量问题优先级分析
- **鱼骨图分析**: 质量问题根因分析
- **能力分析**: 过程能力评估和改进

### ⚠️ 不合格品管理
- **不合格记录**: 不合格品登记和跟踪
- **处理流程**: 不合格品处理流程管理
- **纠正措施**: 纠正措施制定和执行
- **预防措施**: 预防措施计划和实施

### 🚚 供应商质量管理
- **供应商评价**: 供应商质量能力评估
- **供应商审核**: 定期审核和评估
- **绩效管理**: 供应商质量绩效跟踪
- **改进计划**: 供应商质量改进计划

### 📋 文档管理
- **质量标准**: 质量标准文档管理
- **作业程序**: 质量作业程序文档
- **质量记录**: 质量记录归档和查询
- **质量手册**: 质量管理体系手册

### ⚙️ 系统设置
- **用户管理**: 用户账户和权限管理
- **角色权限**: 角色定义和权限分配
- **系统配置**: 系统参数和配置管理
- **安全设置**: 系统安全策略配置

## 技术架构

### 前端技术栈
- **Vue 3**: 现代化的JavaScript框架
- **Composition API**: Vue 3组合式API
- **Element Plus**: 企业级UI组件库
- **ECharts**: 专业的数据可视化图表库
- **Vue Router**: 单页应用路由管理
- **Vite**: 快速的构建工具

### 样式技术
- **SCSS**: CSS预处理器
- **响应式设计**: 支持多设备访问
- **质量检测特效**: 专业的质量管理视觉效果

### 特色功能
- **质量检测动画**: 专业的质量检测粒子效果
- **实时数据更新**: 质量数据实时监控
- **智能预警系统**: 质量异常智能预警
- **移动端适配**: 支持移动设备访问

## 快速开始

### 环境要求
- Node.js 16.0+
- npm 7.0+

### 安装步骤

1. **克隆项目**
```bash
git clone [项目地址]
cd 06-QMS质量管理系统
```

2. **安装依赖**
```bash
npm install
```

3. **启动开发服务器**
```bash
npm run dev
```
或者直接运行启动脚本：
```bash
start-qms-server.bat
```

4. **访问系统**
打开浏览器访问: http://localhost:3003

### 构建部署

```bash
# 构建生产版本
npm run build

# 预览构建结果
npm run preview
```

## 开发指南

### 添加新页面
1. 在 `src/views/` 下创建新的Vue组件
2. 在 `src/main.js` 中添加路由配置
3. 在布局组件中添加菜单项

### 自定义样式
1. 在 `src/styles/variables.scss` 中定义变量
2. 在 `src/styles/index.scss` 中添加全局样式
3. 在组件中使用scoped样式

### 添加特效
1. 在 `src/utils/qualityEffects.js` 中添加新特效
2. 在组件中引入和使用特效
